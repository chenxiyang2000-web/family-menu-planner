# 家常菜单：ALL / START / LIST

零依赖的家庭点菜与菜单计划网站。数据保存在浏览器本地，可直接使用静态服务器运行。

## 主要功能

- ALL：包含“全部、肉类、蔬菜、主食、甜品、超大菜、其他”，每类独立分页且每页最多 20 道；菜品详情可编辑价格
- 超大菜：ALL 和点菜页提供独立分类，可手动点选，但智能生成、预算生成和空白自动补齐均不会选中
- START：以“文件夹 → 菜单 → 点菜/生成”管理菜单，并支持逐层返回
- 简化点菜：菜品卡仅显示图片、名称与加入操作，提交后自动分配
- 点菜数据源：直接读取 ALL 的统一菜品库，不保存副本，也不提供独立导入或更新
- 智能生成：严格按人数标签、餐次、健康目标和忌口筛选
- 健康结构规划：均衡、清淡、高蛋白、低糖分别配置肉类/蔬菜/主食/其他比例；标签仅用于同品类内辅助排序
- 随机餐次模板：1–2人每餐两道肉/菜、一个主食、一个甜品或其他；2人以上每餐“人数+1”道肉/菜并搭配主食和甜品/其他
- 生成顺序固定为肉类、蔬菜、主食、甜品、其他，同品类菜品随机选择
- 菜单预算：每个菜单独立保存总预算，智能生成优先选择预算范围内的菜品；LIST 显示该菜单预算、预估总价和差额
- 空白选项：每天可添加任意数量的空白位置并自动补齐
- 自选菜品拖放：自选菜品生成后可拖动到任意一天的早餐、午餐或晚餐，移动后 LIST 自动同步
- LIST：先选择文件夹、再选择菜单，按菜品名称合并数量，并依据 ALL 菜品价格显示预估总价
- 菜单展示：按日期和餐次分层，菜品分类自动显示图标
- 文件夹删除：确认后级联删除其中菜单，避免孤立数据
- 文件夹创建：使用页面内表单，创建后直接进入新文件夹；即使没有任何既有菜单也能继续创建菜单
- 交互优化：菜单创建改为状态驱动渲染，搜索输入增加短延迟合并，减少频繁整页刷新
- 旧数据迁移：自动读取 `family-menu-planner-v1` 并迁移到新版结构

## 项目结构

- `index.html`：页面入口
- `styles.css` / `upgrade.css`：基础样式与升级功能样式
- `js/storage.js`：文件夹、菜单、菜品数据模型，本地保存和旧数据迁移
- `js/logic.js`：菜单分配、生成、空白填充及采购汇总
- `js/app.js`：页面渲染和交互

## 本地运行

```powershell
python -m http.server 4173
```

然后访问 `http://127.0.0.1:4173/`。
